# @aiqa/cli

`npx pnpm aiqa <command>` from the repository root.

| Command                                                                                       | What it does                                                                                                                                                                                                                                                               |
| --------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `aiqa new page <name> [--target saucedemo] [--path /] [--url] [--dry-run] [--force]`          | Writes a page object to `playwright-framework/src/pages/<target>/` and a starter spec to `tests/generated/`. With `--url` it opens the page and builds `getByRole` locators from its accessibility tree (unique, named elements only). Never overwrites without `--force`. |
| `aiqa history [--suite ui] [--limit 15]`                                                      | Recorded runs from `.aiqa/history`, newest first.                                                                                                                                                                                                                          |
| `aiqa flaky`                                                                                  | Tests that passed only on retry or flipped green/red at least twice.                                                                                                                                                                                                       |
| `aiqa perf [--all] [--fail-on-regression]`                                                    | Performance metrics against the median of their previous runs: regressed and improved first, steady ones with `--all`. A verdict needs 3 earlier runs.                                                                                                                     |
| `aiqa data <customer\|product\|order\|shop> [--count 1] [--seed 1]`                           | Seeded test data as JSON. Same seed, same data.                                                                                                                                                                                                                            |
| `aiqa quiz [--topic security] [--level senior] [--count 10] [--seed 7] [--list] [--coverage]` | Interview questions from [`@aiqa/interview-learning`](../interview-learning): answer, press Enter for the outline and the files that show it, mark yourself, then get the files to revisit. `--list` prints everything without prompts.                                    |
| `aiqa agents triage [--suite ui] [--run <id>] [--limit 10]`                                   | The Triage agent on the latest run of a suite: product, test, flaky or environment for each failed test, with evidence and a next step. Rules first; a model only when configured.                                                                                         |
| `aiqa agents eval triage [--model-only] [--only <ids>]`                                       | Scores Triage on its 30 labelled failures; exit code 1 below the 80% gate. `--model-only` switches the rules off to measure the model alone.                                                                                                                               |
| `aiqa agents log [--limit 20]`                                                                | Every agent run, newest first: source (rules or model), tool calls, time, model, result.                                                                                                                                                                                   |
